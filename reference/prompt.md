# Project Overview

Build a premium, modern, highly interactive website for **Workshop.DevTrackAcademy**.

This platform is dedicated exclusively to **live practical workshops**, where students build complete projects alongside instructors rather than watching passive lectures.

The website should immediately communicate that these are **small-batch, mentor-driven workshops** with limited seats, practical assignments, and real implementation.

Unlike traditional webinars, every workshop should feel like joining an intensive bootcamp.

The experience should feel energetic, premium, handcrafted, and alive.

The website should combine the storytelling of Apple, the polish of Linear, the interactions of Framer, and the boldness of Neo Brutalism.

# Performance

* Use Server Components wherever possible.
* Client Components only for animations and authentication.
* Lazy-load heavy illustrations.
* Optimize fonts and images.
* Respect `prefers-reduced-motion`.
* Ensure accessibility with semantic HTML, keyboard navigation, and sufficient color contrast.

---

# Overall Experience

The final website should feel like a **premium live coding bootcamp** rather than an event registration page. Every interaction should reinforce that these workshops are **small, hands-on, mentor-led experiences** where students actively build real projects, complete assignments, receive feedback, and finish with deployable work. The Neo-Brutalist design should be bold, playful, and memorable, while GSAP storytelling, Framer Motion micro-interactions, and smooth scrolling create a polished, modern experience consistent with the DevTrackAcademy ecosystem.
